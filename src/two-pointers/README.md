# Two-Pointer Drills

Two-pointer setups thrive when the input is sorted or when one pointer marks the start of a candidate while the other expands the end. Decide whether the pointers should move toward each other, chase with different speeds, or sweep in the same direction while maintaining a window.

## Reasoning playbook

- On sorted arrays, move inward based on sum comparisons (water container, two-sum II).
- Use slow/fast pointers to filter characters (palindrome validation, subsequence checks).
- Deduplicate solutions by skipping identical values after confirming a result (three-sum).
